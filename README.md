# JobFlow

JobFlow is a job application management and analytics platform designed to help job seekers organize, track and improve their job search.

## Project Goals

- Track jobs and applications
- Manage application statuses
- Store CVs and related documents
- Analyze job requirements
- Match jobs against a user's profile
- Provide job-search analytics
- Automate reminders and notifications

## Tech Stack

The project will gradually introduce:

- Java
- Spring Boot
- PostgreSQL
- React & TypeScript
- Apache Kafka
- Docker
- Kubernetes
- AWS
- Prometheus & Grafana
- GitHub Actions
